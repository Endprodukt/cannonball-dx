As of October 2026:

- ROAD ENHANCEMENT (VIDEO ENHANCEMENTS menu, 2X engine resolution and above) smooths the
  road edges and markings between native scanlines and filters the whole-pixel jitter of
  the original road data. The filter is limited to 0.75 native pixels, so road and
  roadside sprites cannot drift apart, but a faint remaining unevenness of under one
  native pixel may still be seen on very large displays. The option can be switched off.

- Linux / Steam Deck (untested by the maintainer, community reports only):
  - The Linux package now ships its own TinyXML2 in lib/, so no extra library has to be
    installed on SteamOS.
  - GAMEPAD bindings stored for a controller that is no longer connected are handed to the
    connected controller. This covers Steam Input, which replaces the physical pad with a
    virtual one when the game is started as a non-Steam shortcut. Confirmed by two Steam
    Deck testers. Raw-axis fallback bindings and custom MENU ACCEPT/BACK/PAUSE bindings
    stay tied to their original device and have to be rebound.
  - Random crashes and one freeze (picture and controls stopped, audio kept playing) were
    reported on SteamOS. No log or reproduction is available. Suspected cause: with four or
    more CPU cores the Linux build ran game logic, SDL event handling and menu code on a
    worker thread, a mode never exercised by the Windows build. Thread auto-detection is
    now limited to 3 on all platforms; "-t 4" still selects the old behaviour. Needs
    confirmation from testers.

As of September 2025:

- Audio may not play after system restart. This is caused by the SDL device ordering
  changing on some systems at each boot. Future revision may include the option to select
  audio device by name to resolve this.
  
- Some steering wheels expose more buttons or controls than SDL can use, and in these cases
  some buttons or controls may not be recognised. A mapping entry is required in
  res/gamecontrollerdb.txt for affected devices.
